## 角色与边界
你负责本项目的【前端监控平台】。
- 允许修改：`frontend/`
- 不得修改：`contracts/`、`backend/`、`robot_sim/`

## 本轮任务
用 React + TypeScript 创建监控页面，通过 **Mock API + WebSocket** 展示机器人位置、车辆电量、任务进度、五路充电状态、机器人剩余电量和事件日志。此阶段不依赖真实后端完成。

## 需要实现
- 校园示意地图（SVG）：基站、A/B/C 停车区、车位、车辆编号及电量颜色、机器人位置与朝向（P4 再细化路径与障碍）
- 右侧任务面板：当前任务、目标车辆 5 辆、机器人状态、机器人电量、本批进度 x/5
- 五张充电通道卡片：车辆、电量、进度、状态；**单车对接失败不能遮住其他通道**
- 控制条：启动 / 暂停 / 恢复 / 复位 + 倍速切换（1x / 10x / 60x）
- 事件日志列表（可按类型筛选）
- WebSocket 数据绑定与断线重连提示

## 强制要求
- 页面显著位置标注"**仿真模式／模拟车辆数据**"
- 状态颜色统一，适配答辩电脑与投影（大字号）
- 不出现无响应的死按钮

## 必须交付
1. 可运行代码
2. 启动命令：`npm install && npm run dev`
3. 组件测试或界面截图
4. frontend/README.md 更新
5. 已知问题与未完成事项

## 验收条件
- 点击一次"启动系统"，页面自动演完整个 Mock 流程，无需人工点击"确认对接"或"确认充电"
- 所有模拟数据有明显"仿真"标识
- 页面在投影分辨率下可读

完成后停止，不要自行扩展下一阶段需求。
