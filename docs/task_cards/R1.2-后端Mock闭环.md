## 本轮任务
用 FastAPI 实现 `contracts/api.md` 中 v1.0.0 的全部端点。先用 **MockRobot** 模拟机器人从基站前往停车区，依次经过 IDLE → NAVIGATING → DOCKING → CHARGING → 离开 → RETURNING/RECHARGING 状态，不依赖 ROS 2。

## 需要实现
- GET /api/scenario、/api/vehicles、/api/robot、/api/tasks、/api/events
- POST /api/simulation/start、/pause、/resume、/reset、/speed
- POST /api/demo/obstacle（Mock 记录临时障碍）
- WS /ws 推送 RobotTelemetry / VehicleTelemetry / TaskEvent，按后端仿真时钟 tick
- 每次最多选 5 辆车（按 contracts/simulation_params.md 的打分公式），更新车辆 SOC、机器人 SOC、任务进度、事件日志
- 能源模型：移动扣能、充电扣机器人储能、传输损耗、预计无法完成不派发、低电量 RETURNING → RECHARGING
- 所有响应带 `simulation: true` 标识

## 必须交付
1. 可运行代码
2. 启动命令：`uvicorn backend.main:app --reload`
3. 自动化测试：pytest 覆盖"启动一次自动完成两批 Mock 任务"
4. backend/README.md 更新
5. 已知问题与未完成事项

## 验收条件
- 不依赖 ROS 2
- 调用一次 POST /api/simulation/start 后自动完成两批模拟任务（含五路充电、一批结束离开、低电量返基站补能）
- WS 推送状态与 GET /api/robot 一致
- pytest 全绿

完成后停止，不要自行扩展下一阶段需求。
