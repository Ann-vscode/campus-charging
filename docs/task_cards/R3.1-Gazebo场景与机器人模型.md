## 角色与边界
你负责本项目的【机器人仿真】。
- 允许修改：`robot_sim/`
- 不得修改：`contracts/`、`backend/`、`frontend/`

## 本轮任务
在 `robot_sim/` 中搭建 Gazebo 校园示意环境 + 差速机器人模型，配置里程计与激光雷达等导航所需传感器，提供启动脚本。

## 需要实现
- Gazebo world：基站、道路、A/B/C 停车区、静态障碍；布局与 `scenarios/campus_basic.yaml` 一致
- 差速机器人 URDF/xacro：激光雷达 + 里程计 + 正确的 TF 变换
- 启动脚本：`ros2 launch robot_sim campus_world.launch.py`（一键起 Gazebo + 机器人）
- 验证指令：可通过 cmd_vel / teleop 让机器人移动，确认 `/odom` 与 `/scan` 话题有数据
- README 写明 ROS 2 发行版与版本一致性要求（TurtleBot3 / ros_gz / Gazebo / Nav2 必须同发行版）

## 实施策略（重要）
**先用 TurtleBot3 现成差速模型跑通**，再替换校园地图。第一版不要在 URDF、传感器和坐标变换上死磕——那会把时间耗光。

## 必须交付
1. 可运行代码
2. 启动命令：`ros2 launch robot_sim campus_world.launch.py`
3. 验证脚本（检查 `/odom` 与 `/scan` 数据）
4. robot_sim/README.md 更新
5. 已知问题与未完成事项

## 验收条件
- 仿真稳定启动
- 机器人可通过 cmd_vel 移动
- `/odom` 与 `/scan` 数据正常
- 从基站到 A/B/C 三区位置可目视确认

完成后停止，不要提前做 R3.2 导航（那是下一张任务卡）。
